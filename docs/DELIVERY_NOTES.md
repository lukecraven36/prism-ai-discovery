# Delivery notes

## Completed

- Customer register, customer workspaces, sessions, context and multiple use cases.
- Guided facilitator flow with separate unanswered, unknown and not-applicable states where applicable.
- Versioned deterministic scoring, incomplete score ranges, evidence confidence, gates, risk and ordered classifications.
- Conservative, central and optimistic business-case inputs with capacity/cash separation and payback safeguards.
- Actions, outcome tracking, facilitator recommendation history and decision snapshots.
- Accessible value/readiness matrix plus equivalent portfolio table.
- Dependency-aware roadmap with cycle rejection, shared links, wave effort and budget warnings.
- Print-friendly customer report, Markdown report, CSV register and validated JSON backup/import.
- Labelled and removable demo records, responsive layouts, keyboard-operable controls, visible focus and reduced-motion support.
- Automated acceptance fixtures for calculations, classifications, dependencies, persistence and import validation.

## Remaining limitations

- Storage is local to one browser profile. There is no authenticated shared backend, multi-user collaboration or server-side backup.
- PDF output uses the browser print dialog. Native PDF generation is not included.
- Evidence is captured as text/source references; file uploads are not included.
- Roadmap scheduling is wave-based and deterministic; it is not a production optimiser.
- Official Simpson Associates brand assets and tokens were not retrieved in the restricted build environment. The interface uses an original temporary prism treatment and does not claim those colours or typography as official.
- Browser automation and visual regression tooling are not bundled. Core business rules and storage behavior are automated; final print rendering should be reviewed in the target workshop browser before first customer use.
