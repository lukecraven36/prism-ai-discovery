# Facilitator guide

## Prepare the session

Create the customer, confirm the local-storage notice, and export a backup if continuing an earlier engagement on another device. Create a session with the workshop's local calendar date, facilitator, participants and roles.

## Lead discovery

Start with customer context and business outcomes. Capture several problems before choosing solutions. In guided mode, use the plain-language question first and the supporting guidance only when useful. “Skip for now” leaves an outstanding item; “Unknown” counts as addressed and creates a discovery action.

For scored answers, choose the descriptive rubric rather than working backward from a desired number. Record whether the answer is an assumption, stakeholder estimate or measured evidence. High confidence needs a named evidence source.

## Review the recommendation

Resolve the four required gates, complete the risk review and inspect the possible score ranges. A Validate first recommendation should name the specific uncertainty to resolve. A facilitator recommendation may differ from the calculation, but requires a rationale and remains alongside the calculated result.

Use the business-case scenarios to keep capacity, cash savings, margin, quality benefit and costs distinct. Treat unknown inputs as unknown rather than zero.

## Build the roadmap

Create shared foundations once and link them to every relevant opportunity. Add hard dependencies before scheduling. Prism rejects dependency cycles. Enter wave capacity and budget where known; unknown effort reports that capacity is not fully assessed.

## Close and revisit

Save a decision snapshot before issuing a report. Print or save the customer report as PDF, export Markdown for an editable narrative, CSV for portfolio analysis, and JSON for full backup. Record actual outcomes later beside the original predicted target rather than replacing the forecast.
